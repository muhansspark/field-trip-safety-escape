# 현장체험학습 안전 미션

학생이 실제 현장체험학습 장면을 보고 안전한 행동을 선택하는 정적 웹앱입니다.

- 비숙박형: 공통 19문항
- 숙박형: 공통 19문항 + 숙박 6문항
- 문항 제한 시간: 15초
- 피드백: 최대 5초, 버튼으로 즉시 이동 가능
- 점수: 시작 100점 / 첫 정답 +10 / 첫 오답 -5 / 재도전 정답 +3
- 로그인 및 개인정보 입력 없음
- 서버나 데이터베이스 없이 브라우저에서만 실행

## 실행

정적 파일 서버에서 `index.html`을 열면 됩니다. GitHub Pages에도 그대로 배포할 수 있습니다.

## 파일

- `index.html`: 페이지 기본 구조와 메타데이터
- `styles.css`: 반응형 화면 디자인
- `app.js`: 25문항, 타이머, 점수, 피드백, 완료 화면
- `assets/game/`: 게임에 사용하는 실사형 AI 이미지

게임 속 이미지는 생성형 AI로 만든 학습용 가상 장면이며, 실제 현장에서는 현장 안내와 지도교사의 지도를 따라야 합니다.
